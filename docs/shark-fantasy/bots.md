# Shark Fantasy: bot test (Phase 3a)

Generated by `npx tsx scripts/sf/bots.ts 100` (546 s). Engine sf-engine-0.1, rules sf-game-1.
100 seasons, each in a different generated world, with 24 bots: 4 optimiser, 4 template, 4 setforget, 4 chaser, 8 random.
Bots see only the public view (scouting reports with noise, results, the projection), never the hidden attributes.

## Pass rules (proposed, design §4.4)

| Rule | Result | Target | |
|---|---|---|---|
| Optimiser bots' average beats random bots' average | 100% of seasons | ≥ 80% | PASS |
| Set-and-forget median rank | top 46% | top 60% | PASS |

Also: an optimiser bot beats a random bot head to head 90% of the time; set-and-forget bots' average beats the random bots' in 97% of seasons.

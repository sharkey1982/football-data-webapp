# Model experiments log

Every experiment is recorded here, including the ones that change nothing. Protocol and roadmap: the FixtureShark Modelling Programme Design Report (27 Sep 2026).

From 28 Sep 2026 experiments are also registered in the database before they run (`lab_experiments`: question, benchmark, decision rule, splits) and every result is kept in `lab_scorings` (append-only). **Sealed holdout: 2025/26 and 2026/27** -- no tuning on them; each experiment scores them once, after its rule is registered, and the database refuses a second holdout scoring. Decisions (28 Sep 2026): seal the holdout; if Dixon-Coles adds nothing to the market, match pages keep the model beside the market line and state the gap; Understat xG may be used in the lab only (never displayed); the transfer planner is an internal tool first.
